# 038 V2 相对 V1 的变化

**Supersedes**: `v1`

## 增加

- 增加 038 主体内的白箱可追溯要求。
- 增加任务开始时的账号池与配额快照。
- 增加 R1/R2 实际分配段、正常配额轮换和撞墙接管记录。
- 增加已结束任务按任务查看完整运行事实的验收。
- 增加敏感信息排除和白箱记录不完整时不得误报通过的要求。

## 保持不变

- 多账号池、R1/R2 配额、串行轮询、多轮覆盖和撞墙接管仍属于 038 主体。
- BOSS + 智联平台范围不变。
- 旧账号配置不迁移的规则不变。
- `v1` 文档和已完成任务保持只读历史基线。

## 不在本版本范围

- 不新建独立白箱产品或独立白箱控制台。
- 不新增白箱数据库表或独立 Spec。
- 不改变轮询配额、账号池选择和用户可见主流程语义。
