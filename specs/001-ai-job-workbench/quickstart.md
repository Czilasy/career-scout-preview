# 验证指南

本指南用于实现后的端到端验收，不替代自动化测试。

## 前置条件

1. 安装项目依赖与新增的简历解析、系统凭据依赖。
2. 启动专用 Chrome 并在 BOSS 登录。
3. 启动本地 WebUI。
4. 准备无真实敏感信息的 TXT 测试简历、可测试 AI URL 和临时 Key。

## 验收 A：AI 画像与后台搜索

创建画像，上传测试简历，确认隐私提示。保存 AI URL 和 Key 后测试连接。不填写人工筛选，检查 AI 提取城市与最多 3 组关键词。点击搜索，确认 2 秒内显示搜索中状态，关键词与岗位数持续更新。刷新页面后确认运行恢复。确认首张卡片有岗位、公司、薪资、地点和截断 JD，整卡只打开 BOSS 链接。

## 验收 B：人工回退

使 AI 设置不可用。填写人工关键词和城市后开始搜索，确认任务继续。清空人工关键词再次尝试，确认任务明确失败且不猜测关键词。

## 验收 C：反馈与画像隔离

对卡片点击感兴趣，确认进入收藏入口。对另一张点击不感兴趣并选择原因，确认退场和撤销。撤销后确认卡片恢复。积累 5 条有效反馈，确认只影响后续卡片和下一次运行。上传第二份简历，新建画像，确认旧负向反馈不影响新画像。

## 验收 D：数据安全

检查日志、历史、导出和错误，确认无 Key 或简历正文。删除简历，确认文件与提取文本不可访问，用户确认的画像字段仍可编辑。尝试不受信任链接，确认前端不打开。使用测试数据验证普通结果清理不删除收藏、投递或简历。

## 自动化验证

- 单元：迁移、路径、JSON 输出、简历删除、链接、状态、撤销、清理。
- API 集成：令牌保护、AI 回退、运行恢复、查询预算、流式岗位和画像隔离。
- 浏览器：窄屏、卡片跳转、按钮阻止跳转、JD 截断、入场、退场与撤销。
- 真实来源冒烟：已登录专用 Chrome 上验证有效岗位链接与 JD；自动测试不能替代它。
