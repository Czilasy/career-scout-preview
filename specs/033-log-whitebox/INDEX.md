# 033 Spec 索引

本目录记录“日志白箱与任务完成证据”主体的需求、设计和任务版本。

## 当前版本

- 当前版本：`v2`
- 默认读取：`v2/`
- 当前版本状态：`已冻结，待实施`
- 历史基线：`v1` 保存原 033 平铺文档的完整副本；它解决日志接线和日志卫生问题，但不代表任务完成证据已经统一。
- `v2` 更新：把白箱从“失败后有日志可查”升级为“只有完成证据齐全才能成功”，并统一抓取、AI、恢复、调参、旧流程和前端结论。
- 原目录根部的平铺文档是版本框架启用前的历史入口，本轮按用户要求保留，不作为当前实现依据。

## 版本内容

每个版本成套保存以下文件，不允许跨版本混用：

- `spec.md`：需求与验收基线
- `plan.md`：实现设计与文件边界
- `tasks.md`：执行任务与验证门禁
- `research.md`：查证证据与技术决策
- `data-model.md`：数据与状态模型
- `quickstart.md`：验证指南
- `contracts/`：内部接口与对外返回契约
- `changes.md`：从上一版本到当前版本的变化说明（`v2` 起必需）

## 后续 AI 读取与更新规则

1. 处理 033 相关需求时，先读取本文件，再完整读取当前版本目录。
2. 实施、审查和验证必须明确写明对应 `033 v2`，不得用根目录平铺文件或 `v1` 覆盖当前要求。
3. 同一主体再次改变行为、架构、验收标准、数据边界或失败处理时，新建下一版本并保留旧版本只读。
4. 仅错别字、格式或链接修正不升级版本。
5. 当前版本以本索引为准，不按文件名、目录排序或修改时间推断。
