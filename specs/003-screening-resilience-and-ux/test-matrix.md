状态：仅模拟冒烟与原型交互验收；不连接真实 BOSS 来源、真实登录态、正式 AI 或正式数据库。

## 自动化测试（默认）

```powershell
python -m unittest tests.test_screening_prototype -v
```

这条命令不依赖浏览器自动化工具或 `npx`。它检查原型的模拟边界、临时运行创建时间与长期记录分离、不感兴趣状态、待核验状态、清理入口、窄屏抽屉和安全渲染约束。

## 人工浏览器验收（不属于默认自动化测试）

```powershell
python -m http.server 8765 --directory webui
npx --yes @playwright/cli@0.1.17 -s=phase23 open http://127.0.0.1:8765/screening-prototype.html
```

浏览器验收使用 `screening-prototype.html` 中固定的模拟岗位数据。该固定版本工具只用于本地人工验收，不是项目默认测试依赖；页面不会调用正式后端，也不得把结果写作真实来源验证。
