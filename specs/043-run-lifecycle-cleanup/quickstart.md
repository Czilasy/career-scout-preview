# Quickstart: 043 验证步骤

**前置**：全部使用测试库/临时库与构造数据，不触碰正式库。

- 后端聚焦命令：`uv run python -m unittest tests.test_run_lifecycle tests.test_result_history`
- 前端：`npm test`（在 `webui/`）

## 1. 提醒一次性（US1）

1. 构造一枚"抓完未筛选"的孤儿账本 → 首次启动：灵动岛出现一行来历提醒 + 结果接回展示；
2. 再次启动：无提醒、不自动落该页；第三次启动：同上；
3. 构造旧 A / 新 B 两枚 → 只提示 B；B 被处理或消失后 A 仍沉默（不接力）；
4. 提醒那一次接续做完（开始筛选并收尾）→ 转为正常轮，规则不再适用。

## 2. 数据整条进出（US2）

1. 构造一条流程（轮 + 账本 + 中间档 + 白箱 + 日志）→ 删除轮 → 各表该流程行数归零；
2. 轮仍在（含归档）→ 轨迹查看与补筛数据完好；
3. 同流程存在未结束任务 → 删除被拒绝；
4. 定稿流程 → 更早中间档清零、最新一份保留；
5. 无主账本超过 30 → 最旧的整条清除；被引用或被保护的不动。

## 3. 页面秩序（US3，界面走查）

未筛选轮页面：待筛选标签在左、确认筛选条件按钮在右；常规场景与历史场景布局不变；文案未改动。

## 4. 存量（启动兜底）

用正式库**副本**：启动一次 → 备份产物与清理清单存在；分表行数下降；历史可见性不变；重复启动不重复清理（幂等）。

## 5. 交付链收敛后（仅一次）

后端全量 `uv run python -m unittest discover -s tests` + 前端 `npm test` + `npm run build` + `uv run python -m unittest tests.test_repo_hygiene`。
