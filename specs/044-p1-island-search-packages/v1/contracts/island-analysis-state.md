# UI Contract: 灵动岛“分析中”状态

## Trigger

当现有简历分析阶段进入 analyzing 时，灵动岛展示“分析中”状态。

## Required Behavior

- “分析中”拥有独立内容键，不能复用 idle 或前一运行状态的内容键。
- 内容键变化必须沿用现有测量机制立即重测胶囊宽度。
- “分析中”状态点必须有明确静态颜色，并与抓取、JD 抓取、精筛状态的颜色可区分。
- 分析结束后切换到下一状态时，下一状态内容键再次触发正常测量。
- 减少动态模式可以关闭呼吸动画，但不得让状态点不可见。

## Non-Goals

- 不改变分析任务状态机。
- 不调整其它灵动岛状态的文案、颜色或动画。
- 不重做胶囊布局、通知队列或轮播逻辑。
