# UI Interaction Contract: 历史轮次与顶栏分层

**Date**: 2026-08-11

## Top Bar Hierarchy

常驻（始终可见）：

- 品牌标识
- 本轮状态胶囊
- 提醒（带数字角标）
- 收藏（带数字角标）
- 历史轮次
- 主题切换（图标）
- 设置按钮（图标 + 更新角标）

设置菜单内：

- AI 设置
- 浏览器账号
- 环境检查
- 检查更新 / 新版本
- GitHub 仓库

行为：

- 设置菜单点击外部或 Esc 关闭。
- 菜单项保留现有 `data-testid`（`ai-settings-trigger`、`browser-accounts-trigger`、`env-check-trigger`、`manual-update-check`、`github-link`）。
- 窄屏下常驻文字按钮退化为图标 + `title`，不换行、不重叠。

## History Entry

- 历史入口在任意工作流步骤可用（上传/搜索/筛选/结果页）。
- 点击后打开 `ResultHistoryDrawer.vue`，不强制切换步骤。
- 重新上传简历或“开始新一轮”后，旧最新轮次归档，默认最新视图显示“暂无结果”；历史入口仍可打开。

## History Drawer

- 按 BOSS / 智联分组，组内按时间倒序。
- 每行显示：时间、状态中文、匹配数、待确认数、剔除数、搜索关键词；“最新”行带标记。
- 行点击打开该轮；行内删除按钮带应用内确认弹窗。
- 删除当前打开轮次：关闭该轮并回到抽屉；删除最新轮次：若仍有未归档旧快照则由其接任，否则最近归档轮恢复为最新，无更早轮次显示“暂无结果”。

## Historical Round View

- 打开历史轮次后进入 04 结果页。
- 顶部显示“历史轮次”标识与“回到最新”按钮。
- 平台筛选锁定为该轮平台，不显示“全部”。
- “本轮画像”默认收起，展开后显示完整画像文本。
- 可用操作：导出 CSV、收藏/感兴趣/不感兴趣、查看岗位轨迹。
- 历史轮次状态使用原始机器值的中文映射：完成 / 部分结果 / 失败但有 N 个岗位；失败/中断轮次不显示为“完成”。
- 不可用操作：补抓 JD、全部重抓、重新精筛（或点击后只作用于最新一轮）。

## Top Bar Round Status（B035）

- 运行中：平台名 = 任务平台，文案“抓取/筛选中”。
- 结果态“全部”：不显示单一平台名，数字为合并数。
- 结果态“BOSS/智联”：平台名与数字都只对应当前筛选。
- 历史轮次视图：平台名与数字对应当前打开的历史轮平台。

## Progress Accessibility（B015）

- 进度区主容器不再常驻 `aria-live="polite"`。
- 新增视觉隐藏的播报区域，只在状态、阶段或关键计数（已抓取/已筛选/失败/待确认等）变化时更新。
- 百分比秒级变化不触发播报。
