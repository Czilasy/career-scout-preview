# Quickstart: 多轮结果历史与稳定性整修

**Date**: 2026-08-11

本文件只记录可执行验证场景，不写实现代码。实现阶段按 `tasks.md` 执行。

## Prerequisites

- 本地后端可启动：`uv run python -m webui.app`（或项目现有启动方式）。
- 前端依赖已安装：`webui/` 下 `npm install`。
- 已有测试数据：至少两个平台各两轮 `result_snapshot`。

## 验证：历史列表与打开

1. 启动后端和前端。
2. 在任意步骤点击顶栏“历史轮次”。
3. 确认抽屉按 BOSS / 智联分组，最新一轮有“最新”标记。
4. 点击某一轮，确认 04 页进入历史模式，平台锁定，顶部显示“历史轮次”。
5. 展开“本轮画像”，确认完整文本可见。
6. 点击“回到最新”，确认回到默认最新视图（若最新已被归档则显示“暂无结果”）。

## 验证：归档而非删除

1. 先确认存在一个最新结果。
2. 点击“开始新一轮”或重新上传简历。
3. 打开历史，确认原最新轮仍存在，且不再标记“最新”。
4. 默认最新视图显示“暂无结果”，直到新轮次完成。
5. 检查任务日志仍然存在。

## 验证：保留 30 轮

1. 在测试库中对同一平台写入 32 轮有岗位产出的快照。
2. 触发一次新结果保存或历史列表刷新。
3. 确认该平台只保留最近 30 轮，最旧两轮被删除且任务日志保留。

## 验证：手动删除

1. 打开历史抽屉，选择非最新轮次删除并确认。
2. 确认该轮从列表消失，全局收藏/反馈/岗位库不受影响。
3. 删除最新轮次，确认该平台最新回退：若仍有未归档旧快照则由其接任，否则最近归档轮恢复为最新；无更早轮次时显示“暂无结果”。

## 验证：AI 重试（B034）

1. 用测试替身注入 429/502/超时响应。
2. 前两次失败、第三次成功：任务正常完成。
3. 三次失败：出现明确 AI 错误。
4. 401/403/配额耗尽：不重试，立即失败。
5. 调优 manifest 配置 `retry_limits`：按 manifest 执行。

## 验证：智联误报封禁（B036）

1. 模拟详情页 URL 为 `chrome-error://chromewebdata/` 且文本含“无法访问”。
2. 确认单条返回 `unreachable`，批内其它岗位继续。
3. 模拟文本含“访问被拒绝”，确认仍返回 `blocked`。

## 验证：智联继续身份（B037）

1. 构造智联 paused 筛选任务，冻结身份完整：继续后使用智联 profile，不按 BOSS。
2. 删除冻结身份字段：继续返回错误，任务保持 paused。
3. 缓存写 `logged_in` 但真实 profile 错误：继续前缓存被失效，真实探测不通过。

## 验证：顶栏与语义（B035 / 顶栏分层）

1. 桌面宽度：常驻元素数量符合契约。
2. 窄屏：按钮退化为图标，无重叠。
3. 结果页“全部”/BOSS/智联/历史轮次四种视图，顶栏平台名与数字一致。

## 验证：无障碍播报（B015）

1. 打开屏幕阅读器或检查播报事件。
2. 运行中每秒百分比变化不播报。
3. 状态/阶段/关键计数变化时播报一次。

## 验证：失败/中断轮次（B010 口径）

1. 构造筛选任务在生成岗位后失败、取消或中断。
2. 打开历史，确认该轮出现，状态显示“失败但有 N 个岗位”。
3. 构造无岗位产出的失败，确认不进入历史。
4. 打开失败轮次详情，确认状态不是“完成”。

