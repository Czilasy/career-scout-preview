# B096 V2 统一条件映射契约

**状态**：用户授权 AI 自审后冻结；后续变更须重新确认。
**适用范围**：仅 BOSS 与智联的六个共同字段。
**来源事实**：当前项目已核验的平台筛选 schema；表中使用用户可见标签，实施时解析为对应平台的稳定值。

## 映射总规则

1. “全部”是平台无关的统一条件源，不以 BOSS 或智联为基准。
2. 映射单向、即时生效：统一条件变化后，替换两个平台对应共同字段；平台微调不反向修改统一值。
3. 不能完全对齐时“不漏岗位优先”，选择覆盖目标语义所需的最少平台选项。
4. 多个统一选项同时选择时，各自平台映射取并集并去重。
5. “不限”沿用现有互斥行为：选择不限表示该字段不增加限制，不与其他档位同时提交。
6. BOSS 融资阶段、智联公司性质不属于统一映射；首次不自动选择，用户只能在平台页手动调整。
7. BOSS 的“在校生/应届生”、智联的“MBA/EMBA”及仅单个平台具有明确语义的行业选项不进入统一表，仍可在平台页手动选择。
8. 常用配置和历史保存最终实际值及本映射版本；恢复时不重新执行映射。

## 自审记录

- 薪资和经验表保留“不漏岗位优先”的向外覆盖，并在平台页如实显示实际选择，用户可继续微调。
- 行业表不使用“专业服务直接等同企业服务”“批发零售直接等同电子商务”等单向近似；统一项改为更窄的共同业务语义，必要时映射到智联两个大类。
- 所有映射标签均来自当前 BOSS、智联 schema 或统一业务标签；没有为平台伪造不存在的实际选项。
