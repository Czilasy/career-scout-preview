## 场景一 · 切页/翻历史/刷新不丢现场（B098 A 块）

1. 在当前轮页面四滚到第 3 批、选中第 5 条岗位、详情展开、列表展示筛选草稿设了某档未点确定。
2. 切到页面二再切回页面四 → 滚动位置、选中条、详情开合、草稿全部保留，不回默认。
3. 翻历史第 N 轮看一眼再回当前轮 → 当前轮页面四现场原样接上。
4. 再翻历史第 N 轮 → 第 N 轮查看现场（滚动、选中、详情开合）接上次；第 N 轮无「未确认草稿」只展示已定筛选状态。
5. 刷新页面 → 现场从 sessionStorage 恢复按原样接上。
6. 页面二画像框已撑开高度、区县面板已加载目录并展开 → 切走再回 → 高度、目录、展开状态保留。

**预期**：US1 必须保留项 100% 保留；历史轮懒存只存翻过的；刷新后恢复。

## 场景二 · 只有主体身份变才清（B098 B 块）

1. 画像 A 有历史 3 轮、页面四有现场、城市草稿选了某区。
2. 切换到画像 B → 历史抽屉空、城市回默认、页面四空，画像 B 从干净开始。
3. 切回画像 A → 历史 3 轮、页面四现场、城市草稿原样恢复。
4. 当前轮第 8 轮页面四有现场 → 开新一轮（第 9 轮）→ 第 8 轮降级为历史轮（查看现场保留）、第 9 轮页面四回默认（默认排序、选中第一条、滚到顶、无草稿）。
5. BOSS 平台有草稿 → 切智联 → BOSS 草稿留在 BOSS 不串智联；切回 BOSS 草稿原样。
6. 切页/翻历史/刷新/后台跑完冒泡任一发生 → 现场不被清。

**预期**：只有切画像/开新轮/切平台三场景清；清后达默认态；其他不清（SC-002/SC-007）。

## 场景三 · 灵动岛各态落点正确（B098 C 块）

1. 当前轮第 8 轮跑完、用户正在翻历史第 3 轮 → 点灵动岛 → 切回第 8 轮页面四，历史第 3 轮现场原地保留。
2. 任务暂停在抓取阶段（页面三未启用）→ 点灵动岛 → 落页面二（不落未启用的页面三）。
3. 任务出错在筛选阶段 → 点灵动岛 → 落页面三（按真实进度，不无脑送页面二）。
4. 简历分析中 → 点灵动岛 → 落页面一显示分析中。
5. 启动加载占位期间连点灵动岛多次 → 不吞不锁，加载完成后只执行一次有效落点。
6. 任何点击路径 → 永不出现「页面被清成空白上传页」。

**预期**：各态落点 100% 正确（SC-003）；硬红线无违反。

## 场景四 · 补抓/重抓不切页（B098 D 块）

1. 页面四有现场（滚动/选中/详情开合/草稿）→ 点「补抓 JD」或「全部重抓」→ 不切页、留页面四、灵动岛显示进度。
2. 补抓/重抓进行中 → 查看页面四 → 现场保留不被重置。
3. 完成后灵动岛变跑完态 → 页面四原地展示新结果，岗位内容更新，用户排序方式/选中岗位（按身份跟随）/滚动/详情开合保留。
4. 补抓/重抓中用户想看筛选详情 → 主动点灵动岛去页面三，但不强制切。

**预期**：不切页、现场保留 100%、选中按身份跟随（SC-004）。

## 场景五 · 简历分析中不锁（B093）

1. 上传简历点分析 → 不被锁，分析中可点灵动岛、去历史翻别的轮次。
2. 分析中点灵动岛 → 落页面一显示分析中。
3. 分析中去了历史 → 点「回到最新」：分析完→落页面二；没完→落页面一显示分析中。
4. 分析后台跑完 → 自动进页面二（当前轮流程推进）。
5. 分析失败 → 页面一显示真实失败原因，不出现「浏览器找不到/刷新失败」误报。

**预期**：不锁、后台照跑、按进度落点、不误报（SC-005）。

## 场景六 · 第七类条件（B092）

1. 走只抓取流程（02 页点「直接查看结果」跳过 03 页确认）抓完一轮 → 进结果页确认筛选条件 → 第七类「招聘者活跃时间」跟前六类一起出现，可选项与 03 页一致。
2. 结果页确认条件时选第七类某档 → 确认提交 → 第七类选择生效参与判定。
3. 对比 03 页能设的第七类选项集 vs 只抓取流程结果页确认的第七类选项集 → 两者一致不缺不漏。
4. 03 页筛选条件标题不再硬编码「6 类」（按实际 schema 类数展示）。

**预期**：第七类 100% 出现、可选可确认、与页面二一致（SC-006）。
