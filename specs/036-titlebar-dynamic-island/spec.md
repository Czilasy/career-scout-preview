# Feature Specification: 桌面壳自绘标题栏 + 顶栏胶囊灵动岛

**Feature Branch**: `036-titlebar-dynamic-island`

**Created**: 2026-09-01

**Status**: Draft

**Input**: 用户确认需求（2 块，均在 grill-me 边界质询中逐条确认，含待确认项）：

1. **B084（优化/P1，已确认）· 桌面壳自绘标题栏（无边框窗口）**：Windows 窗口顶部是系统白色标题栏（含最小化/最大化/关闭按钮），与应用内部深色主题强反差、明显不融合，整个窗口看着不像一个整体产品。做窗口无边框 + 页面顶部自绘标题栏。
2. **B088（功能/候选，已确认核心边界）· 顶栏胶囊升级为灵动岛式活组件（数字+动画+可点击）**：顶栏中间小胶囊现在只放一句话（平台 + 状态文案），信息量小、不能点、空闲时直接消失。做成类似灵动岛的活组件：常驻、平时低调、有情况才醒，能展示实时数字、有动画、能点击直达。

## 最高目标（用户原话级，验收/任务的唯一衡量尺）

- **B084**：Windows 用户打开桌面版，窗口顶部没有任何割裂的白色系统标题栏，整个窗口看起来和应用是一个整体；窗口的操作（拖拽/双击/按钮）和记忆（位置/大小/最大化）都像以前一样好用。
- **B088**：任何时候扫一眼顶栏胶囊，就知道这一轮此刻最重要的那件事；需要时点一下胶囊，就到自己该去的地方；正在跑的任务永远不会"找不到"。胶囊上看到的信息，和点进去之后看到的信息，是同一件事，不能对不上。

## User Scenarios & Testing

### User Story 1 - Windows 桌面版顶部是融合主题的自绘标题栏（B084，P1）

Windows 用户打开 Career Scout 桌面版，窗口顶部不再是突兀的白色系统标题栏，而是与当前主题融为一体的自绘标题栏：浅色主题下是白色、暗色主题下是暗色、特殊主题下透明。标题栏可按住拖拽移动窗口、双击最大化/还原，右上角有最小化 / 最大化/还原 / 关闭三个按钮，关闭即退出应用。窗口的位置、大小、最大化状态仍然像以前一样被记住。

**Why this priority**: P1。用户真实反馈的视觉割裂问题，直接影响第一眼产品印象与专业感；是当前最刺眼的桌面体验缺陷。

**Independent Test**: 前端测试（标题栏仅桌面版渲染、按钮交互、主题配色切换）+ 桌面壳窗口状态回归测试（最大化/位置/大小记忆不回归）；Windows 真机 EXE 走查验收（拖拽/双击/按钮/最大化不盖任务栏/关闭退出）。

**Acceptance Scenarios**:

1. **Given** Windows 桌面版启动，**When** 窗口打开，**Then** 窗口顶部无系统白色标题栏，显示与应用主题融合的自绘标题栏。
2. **Given** 标题栏可见，**When** 按住标题栏空白处拖动，**Then** 窗口跟随移动。
3. **Given** 窗口处于普通大小，**When** 双击标题栏，**Then** 窗口最大化；再次双击，**Then** 还原到原来的位置和大小。
4. **Given** 标题栏右上角三个按钮，**When** 点击最小化，**Then** 窗口最小化到任务栏；点击最大化/还原，**Then** 在最大化与普通大小间切换；点击关闭，**Then** 应用退出（保存窗口状态、停止运行中任务）。
5. **Given** 浅色主题，**When** 查看标题栏，**Then** 标题栏为白色；暗色主题下为暗色；特殊主题（万花筒）下为透明，露出主题背景。
6. **Given** 特殊主题，**When** 查看三按钮，**Then** 按钮常态为半透明磨砂底；鼠标悬停 X 变红底、悬停最小化/最大化按钮线条变深色。
7. **Given** 调整窗口位置/大小或最大化后关闭，**When** 重新打开，**Then** 位置/大小/最大化状态恢复（窗口记忆不回归）。
8. **Given** 浏览器模式（非桌面版）打开页面，**When** 查看顶部，**Then** 不显示自绘标题栏。

### User Story 2 - 顶栏胶囊是"一眼知道状况、一点就到现场"的灵动岛（B088，P1）

顶栏中间的小胶囊不再只是显示一句话：它常驻在顶栏，平时低调（空闲时缩成小样，显示当前平台名，点击回主页）；任务跑起来后它"醒"过来，显示实时进度数字（抓取/筛选进度）并带呼吸点，点击回到正在跑的任务；任务跑完显示结果（匹配几个、待确认几个，待确认 >0 时标亮提示），点击去结果页；任务暂停、出错、需要处理时，它变成提醒条（暂停橙色、出错红色），点击去处理现场。任何时刻只展示此刻最值得知道的一件事，不堆叠。

**Why this priority**: P1。它同时解决"一眼看不到任务状况"和"任务在跑却找不到入口"两个实际痛点，是顶栏从"展示"到"活组件"的关键升级。

**Independent Test**: 前端测试——mock 四态数据（空闲/运行中/跑完/需处理）→ 胶囊渲染与切换正确、点击行为正确、数字变化有动画；优先级规则（多态并存取最高一件）用例；减少动态设置下动画退化为静态。

**Acceptance Scenarios**:

1. **Given** 无任务、无结果，**When** 查看顶栏，**Then** 胶囊常驻显示当前平台名，点击回主页。
2. **Given** 任务抓取/筛选中，**When** 查看胶囊，**Then** 显示实时进度数字（如抓取 128/300、筛选 45/128）与呼吸点，数字随进度变化；点击回到正在跑的任务。
3. **Given** 任务跑完，**When** 查看胶囊，**Then** 显示结果（匹配 N · 待确认 M）；待确认 >0 时该数字标亮提示；点击去结果页。
4. **Given** 任务暂停，**When** 查看胶囊，**Then** 变为橙色提醒；点击去暂停现场。任务出错时胶囊为红色提醒，点击去处理现场。
5. **Given** 同时存在多种情况（如运行中且有待确认），**When** 查看胶囊，**Then** 只展示优先级最高的一件（需处理 > 运行中 > 有结果 > 空闲），不堆叠。
6. **Given** 任务在后台运行、用户正在看历史或其它页面，**When** 查看胶囊，**Then** 胶囊仍显示运行态，点击回到该任务。
7. **Given** 状态切换或数字变化，**When** 观察胶囊，**Then** 有动画（数字跳动、展开收缩、"醒"的过程、呼吸点、待确认标亮）；系统开启"减少动态"时动画退化为静态变化。
8. **Given** 主题为明暗，**When** 查看胶囊，**Then** 样式跟随主题色；特殊主题下胶囊半透明保证可见。
9. **Given** 胶囊显示结果（匹配 N · 待确认 M），**When** 点击去结果页，**Then** 结果页上真实展示 N 个匹配、M 个待确认（与胶囊数字一致，不是旧一轮、不是空页）。
10. **Given** 任务正在跑、胶囊显示进度数字，**When** 点击回到任务页，**Then** 任务页显示与胶囊一致的实时进度（数字一致、是当前这一轮），不是历史轮或空进度。
11. **Given** 任务在后台运行、用户正在历史模式浏览，**When** 查看胶囊，**Then** 胶囊显示的是当前正在跑的这轮的真实状态（进度/运行态），不是历史轮的数字；点击回的是当前任务。
12. **Given** 存在各类待提醒事项（投递、待确认、出错、跑完），**When** 查看提醒按钮，**Then** 按钮显示各类提醒的真实数量；点击打开提醒抽屉，抽屉里能看到对应提醒内容，数量与按钮一致。

### Edge Cases

- **B084-首次使用无主题偏好**：默认暗色主题下标题栏为暗色，与其他主题一致切换。
- **B084-最小窗口**：窗口缩到最小尺寸（1024×700）时标题栏内容与按钮不挤压、不溢出、不重叠。
- **B084-最大化边界**：最大化时窗口覆盖工作区但不覆盖任务栏，还原回到原普通矩形。
- **B084-多屏**：窗口跨屏移动、在副屏最大化后关闭重开，位置/大小记忆不回归、不越界。
- **B084-窗口记忆损坏**：无记忆/损坏/污染记忆时仍按既有首开策略处理（默认尺寸+最大化），标题栏不受影响。
- **B088-空闲无平台记录**：从未选择过平台时，空闲态平台名显示默认平台（BOSS），不显示空/异常。
- **B088-进度数字缺失**：抓取/筛选进度暂无总数（未知总量）时，显示已抓/已筛数量，不显示假分母、不报错。
- **B088-无待确认**：待确认数为 0 时，胶囊不显示待确认数字，只显示匹配数。
- **B088-多态并存**：需处理（暂停/出错）与运行中/结果同时存在时，只展示需处理这一件，处理完回到下一优先级。
- **B088-历史模式**：用户在历史模式中浏览时，胶囊仍反映"当前一轮"的真实状态，点击回当前任务而非旧轮次。
- **B088-后台任务完成**：任务在后台跑完、用户不在任务视图时，胶囊进入结果态（显示结果数字），点击去结果页。
- **B088-减少动态**：系统开启"减少动态"时，动画全部退化为无动画的静态状态切换，功能不受影响。

## Requirements

### Functional Requirements

- **FR-001**: Windows 桌面版窗口 MUST 无系统标题栏（无边框），由应用自绘标题栏替代。
- **FR-002**: 自绘标题栏 MUST 支持按住空白区域拖拽移动窗口。
- **FR-003**: 自绘标题栏 MUST 支持双击切换最大化/还原。
- **FR-004**: 自绘标题栏 MUST 提供最小化 / 最大化/还原 / 关闭三个按钮，且功能正确。
- **FR-005**: 关闭按钮 MUST 走既有退出流程（保存窗口状态、停止运行中任务、退出应用），MUST NOT 引入系统托盘最小化。
- **FR-006**: 自绘标题栏 MUST 仅在桌面版显示；浏览器模式 MUST NOT 显示。
- **FR-007**: 自绘标题栏左侧 MUST 显示纯文字 `Career Scout`。
- **FR-008**: 自绘标题栏背景 MUST 跟随主题：浅色主题=白、暗色主题=暗、特殊主题（万花筒）=透明。
- **FR-009**: 特殊主题下三按钮 MUST 常态为半透明磨砂底；悬停 X 为红底、悬停最小化/最大化按钮线条变深色。
- **FR-010**: 窗口记忆（位置/大小/最大化状态、多屏钳制）MUST 保持既有行为不回归。
- **FR-011**: 窗口 MUST 保持边缘可调整大小，最小尺寸 1024×700；最大化 MUST 覆盖工作区但不覆盖任务栏。
- **FR-012**: 顶栏胶囊 MUST 常驻；空闲时低调显示当前平台名，点击回主页。
- **FR-013**: 胶囊 MUST 支持四态：空闲 / 运行中 / 跑完 / 需处理；多态并存时 MUST 按"需处理 > 运行中 > 有结果 > 空闲"只展示一件，不堆叠。
- **FR-014**: 运行中胶囊 MUST 显示实时进度数字（抓取/筛选进度）与呼吸点，点击 MUST 回到正在跑的任务。
- **FR-015**: 跑完胶囊 MUST 显示结果数字（匹配数、待确认数）；待确认 >0 时 MUST 标亮提示；点击 MUST 去结果页。
- **FR-016**: 需处理时胶囊 MUST 变提醒态（暂停=橙色、出错=红色），点击 MUST 去处理现场。
- **FR-017**: 胶囊 MUST 消费统一的实时状态信息（状态/平台/进度/匹配/待确认），MUST NOT 自行重复抓取数据。
- **FR-018**: 胶囊状态切换与数字变化 MUST 有动画（数字跳动、展开收缩、"醒"的过程、呼吸点、待确认标亮）；系统"减少动态"开启时 MUST 退化为静态切换。
- **FR-019**: 任务在后台运行、用户查看其它视图时，胶囊 MUST 仍显示运行态，点击 MUST 回到该任务。
- **FR-020**: 胶囊样式 MUST 适配主题：明暗主题用主题色；特殊主题下半透明保证可见。
- **FR-021**: 提醒按钮 MUST 扩展为通用提醒入口：在现有"投递提醒"基础上，可显示各类提醒的数量（含投递、待确认、出错、跑完等），点击仍打开提醒抽屉查看提醒内容。

### Key Entities

- **窗口状态**: 桌面窗口的普通矩形（位置/大小）与最大化标记；自绘标题栏不改变其语义与记忆机制。
- **主题**: 明暗（浅色/暗色）与特殊主题（万花筒）；决定标题栏与胶囊的外观。
- **胶囊状态**: 顶栏胶囊的实时状态：空闲/运行中/跑完/需处理，含平台、进度、匹配数、待确认数。
- **任务运行信息**: 当前任务的抓取/筛选进度与结果数字；由现有任务状态层汇总后供胶囊消费。

## Success Criteria

### Measurable Outcomes

- **SC-001**: Windows 桌面版启动后窗口顶部无系统标题栏，自绘标题栏与主题融合（浅色白/暗色暗/特殊主题透明）。
- **SC-002**: 标题栏拖拽移动、双击最大化/还原、三按钮、关闭退出全部功能正确。
- **SC-003**: 调整位置/大小/最大化后关闭再打开，窗口记忆全部恢复（回归零例外）。
- **SC-004**: 浏览器模式不显示自绘标题栏。
- **SC-005**: 胶囊常驻，四态显示正确，各态点击都能到达对应位置（主页/任务/结果/处理现场）。
- **SC-006**: 运行中胶囊实时进度数字正确且随任务推进变化（不出现错误、假数字或死数字）。
- **SC-007**: 任务后台运行、用户看别处时，胶囊仍显示运行态并可点击回到任务。
- **SC-008**: 胶囊动画存在且系统"减少动态"时正确退化为静态。
- **SC-009**: 胶囊上看到的信息与点进去看到的页面信息一致——点去结果页，页面匹配/待确认数与胶囊一致；点回任务页，页面进度与胶囊一致（是当前一轮，不是旧轮/空页）。
- **SC-010**: 用户在历史模式浏览时，胶囊仍显示当前正在跑的这轮的真实状态，点击回当前任务而非旧轮。
- **SC-011**: 提醒按钮显示各类提醒的真实数量（投递/待确认/出错/跑完），点开提醒抽屉内容与数量一致。
- **SC-012**: 聚焦测试 + 后端全量测试 + 前端测试 + `npm run build` + 仓库卫生检查全部通过。
- **SC-013**: Windows 真实 EXE 端到端走查全部通过（用户视角验证 B084 全项 + B088 四态与点击 + 数字一致 + 历史模式 + 提醒按钮）。

## Verification Scope

- 功能交付：聚焦测试（标题栏渲染条件/交互、窗口状态回归、胶囊四态渲染/优先级/点击/动画、胶囊数字与目标页一致性、历史模式当前轮真实性、提醒按钮通用化）+ 后端全量测试 + 前端测试 + `npm run build` + 仓库卫生检查。
- 用户端到端真跑验证在交付后进行（Windows 真实 EXE）：①无系统标题栏且主题融合；②拖拽/双击/三按钮/关闭退出；③窗口记忆回归；④胶囊四态显示与点击直达；⑤后台任务运行态胶囊可回任务；⑥动画与减少动态；⑦点去结果页/任务页，页面信息与胶囊数字一致；⑧历史模式下胶囊显示当前轮真实状态；⑨提醒按钮数量与抽屉内容一致。
- 不涉及版本提升/打包/发布；README 是否需同步，实现收敛后检查。

## Assumptions

- **A1（标题栏高度）**: 自绘标题栏高度默认 36px，可微调；以视觉融合为准，不强制精确值。
- **A2（空闲态平台名来源）**: 空闲态平台名显示最近一次使用的平台；从未使用时显示默认平台 BOSS。
- **A3（平台范围）**: B084 本轮仅 Windows；macOS 保持原生标题栏不动（用户无此问题反馈）。
- **A4（B084 与 B082 关系）**: 自绘标题栏复用既有窗口状态域（位置/大小/最大化记忆、多屏钳制），不重写该机制。
- **A5（动画实现）**: 动画基于现有前端样式机制实现，不引入第三方动画库。
- **A6（胶囊数据源）**: 胶囊不做数据抓取，只消费由任务状态层汇总上抛的完整状态信息。
- **A7（B088 与 035 关系）**: 顶栏区域可能与其他进行中的工作（035 顶栏冒泡提示）位置相邻；本 Spec 独立实现胶囊能力，不依赖 035 交付，若 035 先行合入产生顶栏区域小冲突，届时对齐处理。
- **A8（提醒按钮通用化）**: 提醒按钮显示各类提醒的数量（含投递、待确认、出错、跑完），数量由既有提醒状态层汇总；点击仍打开提醒抽屉展示各类提醒内容。本轮按用户确认（Q1=B）纳入实现范围。
