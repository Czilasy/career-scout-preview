# Data Model: Windows 桌面窗口交互

本功能不新增数据库实体。数据模型由持久化的 schema 3 窗口记忆、运行时窗口状态和非持久化原生适配器状态组成。

## 1. WindowMemory（窗口记忆）

持久化位置：当前用户的 `desktop_window.json`。

| 字段 | 类型 | 语义 | 校验 |
|---|---|---|---|
| `schema` | integer | 数据形状版本 | 保持 `3` |
| `default_width` | integer | 无有效普通记忆时的默认宽度 | 默认 1400；必须为正值，读取后受工作区约束 |
| `default_height` | integer | 无有效普通记忆时的默认高度 | 默认 800；必须为正值，读取后受工作区约束 |
| `width` | integer | 最近普通窗口逻辑宽度 | 普通状态产生；必须为正值，读取后钳入可用工作区 |
| `height` | integer | 最近普通窗口逻辑高度 | 普通状态产生；必须为正值，读取后钳入可用工作区 |
| `x` | integer | 最近普通窗口左上角逻辑横坐标 | 可为负以支持左侧副屏；必须与某个当前工作区相交，否则重定位 |
| `y` | integer | 最近普通窗口左上角逻辑纵坐标 | 可为负以支持上方副屏；必须与某个当前工作区相交，否则重定位 |
| `maximized` | boolean | 上次关闭时是否最大化 | 与普通矩形分离；不得改变 `width/height/x/y` 语义 |

### 生命周期

```text
无文件/损坏文件
  → 默认普通矩形 1400×800（按工作区约束）+ 首开最大化

有效 schema 3
  → 读取普通矩形
  → 按当前显示器集合修正大小与位置
  → 根据 maximized 决定启动显示状态

普通窗口移动/拉伸
  → 仅更新内存最近普通矩形
  → closing 时单次持久化

进入最大化
  → 冻结最近普通矩形
  → 最大化期间的尺寸/位置事件不得覆盖它
```

## 2. NormalRect（最近普通窗口矩形）

运行时字段：`width`、`height`、`x`、`y`。

不变量：

- 只代表普通状态，不代表最大化或最小化屏幕矩形。
- 全局最多一份，不按显示器建立映射。
- 工作区足够时，稳定尺寸不小于 1024×700。
- 工作区不足时，可暂时小于常规下限，但不得大于可用工作区。
- 移动或拉伸过程可高频更新内存；持久化仍只在既有关闭链路发生。

## 3. WindowDisplayState（窗口显示状态）

枚举：

- `normal`：允许边缘拉伸并更新普通矩形。
- `maximized`：禁用边缘拉伸、允许标题栏拖下还原、冻结普通矩形。
- `minimized`：不处理可见命中，普通矩形保持冻结前值。

状态转换：

```text
normal --顶部释放/双击/按钮--> maximized
maximized --拖下/双击/按钮--> normal
normal|maximized --最小化按钮--> minimized
minimized --任务栏恢复--> 进入最小化前显示状态
normal|maximized --关闭--> 保存普通矩形 + 当前 maximized 标记
```

## 4. MonitorWorkArea（显示器工作区）

非持久化字段：`left`、`top`、`right`、`bottom`、`dpi`。

用途：最大化位置与尺寸、普通窗口最大跟踪尺寸、1024×700 常规下限的物理像素转换、小工作区例外、跨屏顶部释放判定与离屏修复。

工作区必须排除任务栏，不能以整块显示器矩形代替。

## 5. NativeWindowAdapterState（原生适配器状态）

只存在于进程内，不序列化：`hwnd`、`original_proc`、`callback_ref`、`installed`、`last_gate_error`、当前 DPI/工作区。

不变量：一个 HWND 同一时刻只有一个 Career Scout 适配器所有者；失败安装不能留下半安装回调。

## 6. HitRegion（窗口交互区域）

判定优先级：四角 → 四边 → 标题栏空白/标题文字 → 客户区。最大化状态跳过四边四角。区域宽度、高度按当前 DPI 转为物理像素。
