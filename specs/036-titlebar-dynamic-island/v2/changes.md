# 036 v2 变化说明

相对根目录平铺的 036 v1，本版本只更新 Windows 桌面窗口交互。

## 保留

- 自绘无边框标题栏及现有视觉、主题和三个窗口按钮。
- 双击最大化/还原、首次最大化启动和关闭时窗口状态记忆。
- schema 3 中普通矩形与最大化标记分离的语义。
- 灵动岛及其他顶栏业务能力保持原状。

## 改变

- 取消“普通窗口固定 1400×800”的旧决定。
- 增加四边四角八方向拉伸，不显示可见手柄。
- 默认普通大小仍为 1400×800，常规最小尺寸改为 1024×700，最大尺寸随当前显示器工作区变化。
- 增加最大化窗口拖下还原并继续移动。
- 增加普通窗口拖到当前显示器顶部并释放后最大化。
- 用户移动和拉伸后的最近普通窗口矩形纳入可靠记忆。
- 增加 Windows 10/11、混合 DPI、跨屏、小工作区和运行中任务的真实验收门禁。

## 明确不增加

- 左右半屏、四角四分屏或自定义贴靠预览。
- 透明前端边缘层、裸系统粗边框或全页面拖动。
- 标题栏视觉改版、macOS 行为、每显示器独立记忆。

## 工程依赖

`packaging/desktop.py` 已超过 Python 文件规模红线。其既有原生窗口 hook 必须先由独立拆分 Spec 迁移到 `packaging/window_controls.py`；该拆分不是 036 v2 的隐藏实现任务。
