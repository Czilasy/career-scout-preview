# Quickstart: 发现结果页卡片网格化与体验修复

**Feature**: 006-discovery-card-grid  
**Date**: 2026-07-22

## 前置条件

- Python >=3.10，`.venv` 已激活
- Chrome 已启动调试端口（`python scripts/boss_cdp_raw.py --setup-chrome`）
- 已有至少一个画像和一份简历
- 已完成至少一次发现运行（有结果数据可验证）

## 启动

```bash
# 激活虚拟环境
.venv\Scripts\activate

# 启动 Web 服务
python -m webui.app
# 或
flask --app webui.app run --port 5000
```

浏览器打开 `http://127.0.0.1:5000`。

## 验证场景

### V1：卡片网格布局（FR-001）

1. 完成一次发现运行，进入结果页
2. **预期**：岗位以卡片网格排列，桌面宽度下每行 3~4 张
3. 拖动浏览器窗口变窄
4. **预期**：列数自动减少，窄屏下降为单列
5. 检查 JD 区域：**预期**完整 JD 可见，高度自适应内容，无截断省略号
6. 检查卡片内容：**预期**只有三区（标题+薪资+条件 / JD / 按钮），不存在公司名、badges、完整度、原始链接、排序依据、解释等区块

### V2：死元素已删除（FR-002）

1. 在结果页按 F12 打开开发者工具
2. 在 Elements 面板搜索 `discoveryResultsHeader`
3. **预期**：DOM 中不存在该元素
4. 搜索 `discovery-feedback-tools`
5. **预期**：DOM 中不存在该元素
6. **预期**：页面顶部无空白间隙

### V3：横条已移除、按钮已重排（FR-003）

1. 在结果页检查顶部
2. **预期**：看不到「简历驱动发现」横条和「上传简历 · 确认方向 · 发现岗位」文案
3. **预期**：顶部操作栏有 `[重新上传] [AI 设置]` 两个按钮
4. 点击「重新上传」
5. **预期**：回到上传简历步骤

### V4：刷新恢复结果（FR-004）

1. 在结果页按 F5 刷新
2. **预期**：页面自动恢复到结果视图，卡片网格重新渲染
3. 切换到另一个画像
4. **预期**：不恢复前一个画像的运行结果

### V5：岗位名称跳转（FR-005）

1. 在结果页点击某张卡片的岗位名称
2. **预期**：新标签页打开 BOSS 直聘详情页
3. **预期**：原页面卡片状态不变

### V6：标记不感兴趣并恢复（FR-006）

1. 点击某张卡片的「不感兴趣」按钮
2. **预期**：卡片变灰（低透明度 + 灰度滤镜），不消失
3. **预期**：底部出现「恢复」按钮
4. 点击「恢复」
5. **预期**：卡片恢复正常外观

### V7：标记感兴趣（FR-007）

1. 点击某张卡片的「感兴趣」按钮
2. **预期**：按钮文字变为「已感兴趣」
3. 切换到「筛选工作台」视图
4. **预期**：该岗位出现在感兴趣区
5. 回到结果页，点击「已感兴趣」取消
6. **预期**：按钮恢复为「感兴趣」
7. 切换到筛选工作台
8. **预期**：该岗位不再出现在感兴趣区
