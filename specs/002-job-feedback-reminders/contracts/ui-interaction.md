# UI 交互合同：岗位生命周期与提醒

## 信息架构

- 顶部导航新增提醒图标按钮，紧邻收藏。按钮使用 Lucide `Bell`，`aria-label="查看投递提醒"`。
- 徽标显示当前画像全部逾期总数；`0` 时不显示，`1-99` 显示数字，`>=100` 显示 `99+`，可访问名称仍包含真实总数。
- 点击按钮打开右侧 `ReminderDrawer`；抽屉不是页面跳转，也不清除任何提醒。
- 岗位详情中的生命周期操作挂在 `JobWorkspace` 的 `actions` slot，使用 `JobLifecycleActions`。
- 不做功能介绍卡、教程文案或平台筛选。

## `ReminderDrawer`

### 状态

| 状态 | UI 行为 |
| --- | --- |
| loading | 抽屉尺寸稳定；列表区显示加载状态，关闭按钮可用 |
| error | 显示真实失败文案与重试按钮；保留上次成功数据时标记为旧数据，不清空徽标 |
| empty | 显示“当前没有需要跟进的岗位”；不暗示查看已清除 |
| populated | 显示 `total` 与最多 100 项，最长未活动优先 |
| action busy | 只锁定目标岗位的目标动作，其它提醒仍可阅读 |
| advice loading | 只在该岗位建议区显示加载，跟进/荒废按钮不被 AI 请求锁住 |

### 每项内容

- 岗位名、公司、薪资/地点（有则显示）、来源标签、未活动天数。
- `查看岗位`：只有后端投影 `can_open=true` 时启用，使用校验后的 `canonical_url`。
- 快捷命令：记录跟进、标记已荒废、请求建议。
- AI 建议显示 action 标签、reason 和 `AI/规则` 来源；不自动执行。
- 操作成功后该项是否退出由服务端刷新结果决定，不由前端本地删除模拟。

### 导航与可访问性

- 抽屉打开后焦点进入标题/关闭按钮，Escape 关闭，关闭后焦点回提醒按钮。
- 窄屏抽屉占满可用宽度与高度；操作按钮可换行但不逐字竖排、不横向溢出。
- 100 条列表使用单一内部滚动区，页面 body 不产生第二个横向滚动条。

## `JobLifecycleActions`

### 初始读取

- 详情岗位变化时读取当前 profile + 岗位 state。
- 只打开详情不会发送 action。
- pipeline 岗位尚无内部 ID 时，写命令携带冻结结果中的权威三元组；成功响应后缓存内部 `job_id`。
- 身份不完整时禁用写按钮并显示“岗位身份未可靠入库”，不能从当前平台选择补值。

### 显示与命令

- 显示唯一当前状态，不同时显示“感兴趣 + 已投递”等并行状态。
- 主命令按当前状态选择：已读、已投递、记录跟进、标记已荒废、恢复已投递。
- “纠正”打开紧凑表单，可选目标状态并按需编辑投递日期时间。
- 已投递但缺失投递时间时显示明确补充入口，提醒资格显示为不可计算。
- 投递日期控件提交带时区时刻；未来日期在客户端可预警，但服务端仍是权威验证。
- 轨迹按需展开并从事件 API 加载，不把偏好反馈混入。

### 幂等与失败

- 每次用户确认生成 request ID，并在该 fetch 的超时/网络不确定重试中复用。
- 用户明确再次点击“记录跟进”生成新 request ID。
- 写请求期间锁定同一岗位的生命周期按钮，防止并发矛盾操作。
- 不做未经确认的乐观状态更新。成功只采用响应 `state`；失败保留原状态/时间并显示 API 文案。

## 当前画像切换

1. `App.vue` 在 profile 为空时清空徽标并不请求。
2. profile 确定后先加载轻量 reminder count，只有打开抽屉才加载 list；切换时关闭或重置旧抽屉选中项。
3. 使用请求序号或 AbortController；旧 profile 延迟响应不得覆盖新 profile。
4. `DiscoveryView` 和详情动作使用同一当前 profile prop。
5. 任意生命周期 action 成功后发出 `job-feedback-changed`，App 重新查询当前 profile；如果 profile 已切换，丢弃旧 action 的刷新结果。

## 跳转安全

- 只使用后端已入库 `canonical_url`，前端继续执行所属 platform 的 host/path 校验作为纵深防护。
- URL 无效时隐藏/禁用跳转并提供可理解状态；不影响查看详情、跟进、荒废和建议。
- 不用裸平台 ID拼 URL，不从 URL 猜 platform。

## 视口验收

### 1440×900

- 顶部按钮与现有收藏、浏览器账号、AI 设置不重叠。
- 抽屉与主工作台同时可见，列表内部滚动，标题和动作不截断。
- 详情生命周期动作信息层级清晰，不挤压 JD。

### 390×844

- 顶部操作允许自适应但提醒入口始终可达。
- 抽屉全屏，关闭/返回操作固定可达。
- 提醒项动作至少 44px 可点击区域；文字换行但不溢出。
- 日期纠正表单、错误文案、建议和历史均可滚动到达。

## 不允许的交互

- 查看提醒、详情或 AI 建议后自动清除徽标。
- 打开详情自动标记已读。
- AI 建议按钮与“标记已荒废”绑定。
- 平台 tabs/筛选影响提醒。
- snooze、忽略本次、60 天层级或可配置阈值。
- 请求失败后仍显示新状态或把列表项本地移除。
