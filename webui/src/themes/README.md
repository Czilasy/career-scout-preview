# 主题模块

主题代码统一存放在本目录。`registry.ts` 是主题登记、值校验与样式加载入口；`ThemePickerOptions.vue` 和 `picker.css` 负责通用主题选择列表。`ThemeSurfaceHost.vue` 按登记的 `surface` 挂载主题环境组件，切回明暗基座时自动卸载。

亮色与暗色共用 `base/theme.css`，保留平台品牌色和中性色作用域。独立主题各用一个子目录，集中存放样式、组件、动效、资源、预览及专属测试。

`kaleido/` 存放新版万花筒：`theme.css` 负责整套界面样式，`KaleidoscopeField.vue` 管理画布挂载，`renderKaleidoscope.ts` 将同一个变化中的碎片场景镜像为十二个扇区。动效在页面隐藏或系统要求减少动效时暂停，卸载时释放帧回调与监听器。不引用设计预览的模拟业务逻辑。

公共视图、组件和全局样式不得包含独立主题的专属选择器、图案、动效或直接引用主题子目录。通用主题切换、长按 1 秒打开选择框和偏好保存逻辑继续共用；公共标题栏的主题大类规则继续共用。

删除主题时，同步移除模块、登记、挂载、预览、后端合法值及专属测试。已保存的不可用主题按无效偏好处理，不能恢复为没有样式的主题。

设计稿集中在本地 `design/<主题>/`；历史设计稿和 Spec 保留用于回溯，不参与运行时加载。
